# 决赛检查



决赛主要检查各个榜单的决赛的发奖情况是否符合预期。



各个榜单的结束时间是 北京时间 `2026-08-29 23:59:59`，结算定时任务在`2026-08-30 00:35:00~00:40:00` 之间完成，因此在这个区间，榜单没有完成结算也是正常，但是过了这个时间，则结算必须完成。



| 榜单   | 大区        | TOPIC          |
| ------ | ----------- | -------------- |
| 陪陪榜 | in          | player_in_20_1 |
| 陪陪榜 | vi/ko/ph    | player_10_1    |
| 房间榜 | in          | room_in_10_1   |
| 房间榜 | vi/ko/ph    | room           |
| 家族榜 | in          | family_in_10_1 |
| 家族榜 | vi/ko/ph    | family         |
| 用户榜 | vi/ko/ph/in | user           |
| CP榜   | vi/ko/ph/in | couple         |



检查内容：

1. 检查 各个round 的状态 是否是 200
2. 检查奖励发放是否符合预期
   1. 检查奖励对象：给房间、家族、家族内成员、贡献者，以及 对应 player_type 是否符合预期
   2. 检查奖励内容：奖励的内容是否符合预期、数量、时长
